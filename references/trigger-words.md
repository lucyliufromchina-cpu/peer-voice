# Trigger-word scanner / 触发词扫描表

Scan the draft for these. Each hit is a red flag — it almost always means a sentence
is standing *above* the reader. The right-hand column says which of the five moves
fixes it (see `../SKILL.md`).

扫一遍草稿,命中下表即红旗——基本都意味着某句站在了读者之上。右列是用第几个动作来修。

| ❌ Trigger phrase / 触发词·句式 | Why it's 爹味 / 为什么居高 | ✅ Fix (move #) / 改法(动作) |
|---|---|---|
| 没人做 / 一直没人 / 没人看见 / 没人对过账 | Implies "you failed / you're blind" — 暗示你失职、你瞎 | Industry stage or structural fact — 行业刚起步 / 结构使然 (①⑤) |
| 盲区 / 你有个盲区 / 看不见 | Diagnoses the reader's defect — 诊断对方缺陷 | "A layer not yet built up — 还没被系统做起来的一层" (①) |
| 漏损 / 你在漏 / 暴露 / 风险敞口 / 出事 | Scares downward — 向下吓唬 | Upward: "more consistent → easier — 越统一越省心" (③) |
| 没被挖的矿 / 价值洼地 / 你错过了 | "You failed to capture value" — 你没挖到 | "The industry is just starting on this — 行业才刚开始做" (①) |
| 你应该 / 你必须 / 你最好 / 建议你去… | Prescribes / orders — 开药方、下指令 | "We'd suggest… you decide — 做不做你定" (②) |
| 由你牵头最合适 / owner 是你 / 你来主导 | Assigns the reader's org role — 替对方派角色 | "How we work *with* you — 我们怎么和你配合" (②) |
| 用得不错 / 做得挺好 / 你们很棒 | Grades the customer (pat on the head) — 给甲方打分 | Delete, or state a neutral fact — 删 / 中性陈述 (④) |
| 你们是否已经做了 X / 做了吗 / 有没有人在做 | Quizzes, implies a gap — 查岗、暗示缺失 | "We'd like to understand how you do it today — 想了解你们今天怎么做" (②⑤) |
| 让我告诉你 / 你需要知道 / 其实呢… / 说白了你… | Lectures from above — 居高说教 | "One thing we've noticed… — 我们看到的一件事是…" (⑤) |
| 帮你优化 / 教你 / 指导你 / 带你… | Takes the teacher's seat — 摆老师位 | "Together with you / show you what's in the data — 和你一起 / 把…照给你看" (②) |
| 开场先晒"我们做了 A、做了 B、拿了奖" | Flex preamble — 自夸开场 | Lead with a shared discovery or your track record humbly — 用"共同发现"或谦虚的资历开场 (④) |

## Two fast passes / 两遍快扫

1. **Subject pass / 主语扫描** — find sentences whose subject is **"你/你们"** followed by a
   lack, a should, or a verdict. Those are the densest condescension. Re-subject to
   "we / the industry / this".
   找主语是"你/你们"且后面跟着"没 / 该 / 错"的句子,最密集的爹味就在这里,换成"我们/行业/这件事"。

2. **Verb pass / 动词扫描** — flag verbs that put you over them: 教 / 指导 / 优化(替对方) /
   纠正 / 提醒你 / 告诉你. Replace with verbs you can honestly own: 看到 / 做 / 一起看 / 照出来.
   标出把你架在对方之上的动词,换成你能诚实拥有的动词。

> A line is safe when you could say it to a respected peer across the table without
> them feeling talked down to. 一句话,只要你能当面对一位你尊重的同辈说出口、对方不觉得被俯视,就过关。
